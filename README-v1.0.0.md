# Writing Coach v1.0.0 — Chinese Writing Core

This release enables the existing `zh` language module without copying the English app.

Scope:
- Chinese language selector enabled
- isolated `/data/users/<user>/zh/writing.db`
- HSK learning-band targets: HSK1–HSK6 and HSK7-9
- Chinese-specific AI evaluator and error taxonomy
- Chinese writing task generation
- HSK-style practice mode
- Chinese character/unit counter
- shared progress/history/analytics
- shared platform-wide AI engine from v0.9.2
- English behavior preserved

Intentionally deferred to the next Chinese module release:
- Chinese grammar course/library
- Chinese dictionary + pinyin word notebook
- Chinese-specific translation/selection toolbar

Important: the HSK label shown by the app is an internal learning estimate for progress tracking, not an official HSK exam result.
