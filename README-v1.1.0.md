# Writing Coach v1.1.0 — Chinese Learning Library

Adds the second Chinese-language layer on top of v1.0.0.

## Included

- Chinese Library is enabled
- 56 original HSK-oriented grammar lessons (8 per internal learning band)
- AI-generated lesson details with Vietnamese explanation
- Simplified Chinese examples + tone-mark pinyin + Vietnamese meaning
- language-specific lesson progress and cache
- Chinese dictionary powered by the active platform AI provider
- pinyin, Vietnamese meaning, usage notes, examples, collocations, and safe character breakdown
- Chinese → Vietnamese selection translation
- Chinese saved vocabulary notebook
- Han-character selection support in the dictionary toolbar
- backend Chinese writing-unit counter fix
- English library/dictionary remains compatible

## Important

The HSK labels in Writing Coach are internal learning bands. The grammar path is an original learning syllabus for this app and is not an official HSK textbook or official exam specification.

API keys/models are still controlled only through Platform Admin and the shared platform AI layer.
