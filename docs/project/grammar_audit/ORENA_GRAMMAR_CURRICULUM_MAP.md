## Authoring strategy

Large-batch authoring is grouped by:

`target language → level → grammar family`

This prevents one generic template from being reused across unrelated grammar
phenomena while still avoiding lesson-by-lesson manual implementation.

Every batch carries a required visual mode and concept-matched practice modes.
