# Orena Grammar Learning Model v1 — Phase 2 Foundation

Status: **FOUNDATION / NOT YET VISUALLY APPROVED**

This phase extends the existing Static Grammar Knowledge Base. It does not create a
parallel lesson source and it does not mass-migrate the 508 curriculum items.

## Learning flow

A curated teaching lesson must preserve:

**NOTICE → UNDERSTAND → CONNECT → COMPARE → APPLY → RECALL → TRANSFER**

English and Chinese share the renderer architecture, not the same composition.
Chinese word order, particles and aspect use position/insertion/timeline semantics
rather than being converted into English tense terminology.

## Semantic role contract

Rich content uses a validated vocabulary: subject, verb, object, noun, modifier,
article, determiner, auxiliary, preposition, particle, time, location, complement,
classifier, negation, marker, changed, error, exception, connector, topic, comment,
and result. Role text remains visible beside color/border cues.

## Structured mistakes and exceptions

A curated lesson must preserve structured common mistakes when the corresponding
legacy lesson contains mistake content.

Each `common_mistake` block uses:

**incorrect → WHY → correct**

Lessons without a real mistake target are not required to invent one. The optional
context explains when the error happens. `exception` is a separate structured block
with rule, exception, WHY, and optional context.

## Micro-practice interaction contract

`micro_practice` explicitly declares one interaction type: choose, reorder, fill,
match, transform, compare, classify, identify, build, speak, or write. Choice,
reorder/build, match, and text-production primitives produce different evidence
instead of collapsing every task into one textarea.

## Completion evidence

A curated lesson must require learner-input evidence from at least **APPLY, RECALL
and TRANSFER**. Completion remains activity evidence, not CEFR/HSK mastery.

## Localization and mobile

Learner chrome such as flow labels and transformation before/after labels is
localized independently from target-language examples. Pinyin remains toggleable.

**No horizontal scrolling is allowed for core grammar learning content.** Formula
and semantic-sentence parts wrap, and the learning-flow indicator becomes a
multi-row grid on narrow screens.

## Hard gate before mass migration

Representative English and Chinese concepts must pass desktop/mobile visual review,
hierarchy/cognitive-load review, Pinyin review, active-recall review, personal
connection review and transfer review before full migration.

**No full 508-item migration is allowed merely because schema/tests are green.**
