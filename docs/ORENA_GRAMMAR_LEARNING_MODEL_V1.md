# Orena Grammar Learning Model v1 — Phase 2 Foundation

Status: **FOUNDATION / NOT YET VISUALLY APPROVED**

This phase extends the existing Static Grammar Knowledge Base. It does not create a
parallel lesson source and it does not mass-migrate the 508 curriculum items.

## Learning flow

A curated teaching lesson must preserve:

**NOTICE → UNDERSTAND → CONNECT → COMPARE → APPLY → RECALL → TRANSFER**

English and Chinese share the renderer architecture, not the same composition.
Chinese word order, particles and aspect use position/insertion/timeline semantics
rather than being converted into English tense terminology.

## Completion evidence

A curated lesson must require learner-input evidence from at least **APPLY, RECALL
and TRANSFER**. Completion remains activity evidence, not CEFR/HSK mastery.

## Accessibility and memory

Semantic color is not the only signal: role labels, text and shape/border cues stay
visible. Pinyin is toggleable for Chinese rich lessons. Reduced-motion behavior
continues to inherit the global accessibility contract.

## Hard gate before mass migration

Representative English and Chinese concepts must pass desktop/mobile visual review,
hierarchy/cognitive-load review, Pinyin review, active-recall review, personal
connection review and transfer review before full migration.

**No full 508-item migration is allowed merely because schema/tests are green.**
