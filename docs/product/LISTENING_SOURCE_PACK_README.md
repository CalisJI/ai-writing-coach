# ORENA LISTENING — DEVELOPMENT SOURCE PACK

Includes 100 EN and 100 ZH candidate source URLs for development.

Purpose: exercise bulk importer, generate many short lessons, make the dev library visually representative, and test multiple topics/levels/modes.

These are DEVELOPMENT CANDIDATES. The list does not assert that every URL has usable captions, embedding, stable availability, perfect excerpt boundaries, content suitability or production publication rights. The importer should verify metadata, transcript/captions and playback. Failures must be reported rather than silently accepted.

Do not invent timestamps. A longer source may generate multiple natural 20–90 second excerpts.

Workflow: import URL → verify playback → acquire transcript → detect natural boundaries → propose 1–3 excerpts → estimate level → human/editor adjusts metadata → add to DEV catalog → production promotion remains a later separate gate.
