# ORENA — READING PRODUCT SPECIFICATION

Status: Human product specification
Languages: EN + ZH
Core idea: Reading is an interactive comprehension/language-analysis surface, not a static article page.

## Sources
Curated texts, Listening transcripts, imported text, Writing examples, graded stories and short articles/dialogues.

## Interactive text
Tap/click word, phrase, sentence or paragraph for Dictionary, contextual meaning, grammar explanation, translation, Chinese Pinyin/readings, save vocabulary, or explain this passage.

## Linguistic highlighting
Optional consistent color highlighting for useful categories across Reading/Writing/Listening transcript views. Never highlight categories not actually classified.

## Chinese
Hanzi, optional Pinyin, readable word segmentation, contextual meanings and HSK-aware support. Do not turn every character into an isolated vocabulary item.

## Comprehension
Main idea, detail, inference, vocabulary-in-context, sequence, short response and summary. Feedback explains why the answer fits the text.

## Connected learning
Reading → save vocabulary → Library; sentence → Grammar; read aloud → Speaking; respond/summarize → Writing; media transcript → return to same Listening segment.

## Acceptance
Interactive lookup, EN/ZH parity, useful optional Pinyin, contextual explanations, Vocabulary handoff, Speaking/Writing/Listening handoffs and responsive/native parity.
